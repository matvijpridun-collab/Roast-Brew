# Зерно & Чашка

Сайт кафе-магазину свіжообсмаженої кави в зернах. Тут можна переглянути асортимент, дізнатися про обсмаження та залишити контактні дані для замовлення.

## Переглянути сайт

[Відкрити сайт на GitHub Pages](https://matvijpridun-collab.github.io/Roast-Brew/)

## Можливості

- Каталог кави з описами смакових нот
- Адаптивний дизайн для комп’ютерів і мобільних пристроїв
- Плавна навігація між секціями
- Повідомлення при натисканні «До кошика»
- Форма замовлення з демо-підтвердженням
- Метатеги для пошуку та поширення сторінки в соцмережах

> Форма замовлення наразі демонстраційна: дані не надсилаються на сервер.

## Використані технології

- HTML
- CSS
- JavaScript
- Google Analytics

## Структура проєкту

- `index.html` — розмітка сторінки
- `style.css` — стилі та адаптивний дизайн
- `script.js` — інтерактивність
- `img/` — зображення сайту
